📱 Mobile Addiction Analysis

📌 Project Overview

This project explores mobile phone addiction and its potential relationship with stress levels, gender, and academic performance. Using Python and data analysis techniques, the project aims to identify patterns and understand factors associated with mobile addiction.

🎯 Project Objectives

Explore mobile addiction-related data.

Analyze addiction patterns across genders.

Investigate the relationship between stress levels and mobile addiction.

Examine the impact of mobile phone usage on academic work.

Visualize key patterns and relationships in the dataset.

Generate meaningful insights through Exploratory Data Analysis (EDA).
